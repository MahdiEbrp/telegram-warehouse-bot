# نمونهٔ Excel — v1.3.0

`shipments-demo.xlsx` خروجی واقعی نویسندهٔ همین پروژه با **داده‌های کاملاً ساختگی** است: دو مرسوله برای یک سفارش، و یک سفارش بدون مرسوله؛ مجموعاً سه ردیف داده و ۲۱ ستون.

- بارکد `00Ab0091` و کد پستی `0123456789`، متن‌اند؛ صفر ابتدایی/case حفظ شده است.
- مقدار مشتری `=SUM(1,2)` عمداً به‌صورت **متن literal** است، نه فرمول.
- تلفن و نشانی ساختگی هستند؛ این فایل از دیتابیس واقعی یا حساب ابری شما استخراج نشده است.
- دو sheet فارسی، RTL، freeze عنوان و AutoFilter دارد؛ با `openpyxl 3.1.5` مستقل و XML/CRC بررسی شده است. Excel دسکتاپ یا ارسال واقعی Telegram آزمایش نشده است.
- خروجی تولیدی حاوی اطلاعات مشتری واقعی خواهد بود؛ برخلاف این نمونه، نباید عمومی یا فوروارد شود.
